# nx base 生成链路综合文档（2026-08-04）

## 一、base 在 P cookie 中的位置（na 结构）

```
P cookie → b86 decode → encryptMode2(keys16) → dec
dec[4:] = na
na[0:2]   = 4,8 头
na[2:6]   = r2mka（时间戳）
na[6:10]  = start（时间戳）
na[11:59] = keys2（48B，= cd 派生 keys[2]）
na[59:61] = beLen（(na[59]&0x7f)<<8|na[60]）
na[61:61+beLen] = be 段（加密的 base）
```

## 二、base 解码链路（be → base）

```
be → encryptMode2(keys17+time) → tmp → XOR keys2[0:16] → huff
huff → huffman 解码 → raw
raw[0:bestLen] = base（bestLen 通过反向 numarrEncrypt 匹配确定）
```

## 七、唯一障碍

- 输入 = cap + cd + 环境检测值
- 路径：AgentA CDP 捕获生成状态 → 反编译或公式
