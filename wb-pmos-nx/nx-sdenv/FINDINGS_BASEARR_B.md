## 二、字段公式反推

### 2.1 恒定段（硬编码）
- `[0:22]` 固定头（38/38 一致）
- `[137:]` 固定尾（尾部对齐，[110:137] 之后）

### 2.2 指纹段 [29:68]（13 种变体模板库）
变体有共享子块，如：

- A236 同 env（sw=1920/sh=1080/dpr=1/hc=18/tz=-480）下 [29:68] 仍有 4 种 → 环境检测含未捕获维度（canvas/webgl）
- **含义**：13 个指纹模板可硬编码，任选一个（服务器接受合法指纹）

### 2.3 f(nsd,cd) 段（需内层 VM）
- `[22:29]` 会话段：与 env73 配对，同 cd 固定（798 实验）
- `[68:73]` env73：同 cd 固定，19 种模式跨 cd；与 cap/b86/keys2 无简单关系（813 全排除）
- `[110:137]` 变体区：同环境固定

### 2.4 时间/随机段（可随机填充）
- `[73:75]`：同 cd 固定但跨 cd 变（时间/会话分量）
- `[75:110]` 块区前导：随机填充（[70,72-79,81,82] 等长可任意）
- 块类型选择：随机/时间（同 cd 下 D/A/E/C 变，800 实验）

### 2.5 校验和/配对（已发现）
- **[22:29] ↔ [68:73] 配对**：单独改 → 412，一起改 → 200（802/804）
- **base 整体自洽**：混搭不同样本区段 → 412（811）
- **huffman bits 保持**：WAF 校验编码总长度（784）

## 四、纯算法达成度

```
可硬编码: [0:22] + [29:68]指纹模板(13选1) + [137:]固定尾 ≈ 53+39+33 字节
```
