3. **管线 Coder 逻辑本身正确**：用对 nsd 时管线 coder 生成的动态代码与沙箱/浏览器完全一致。**kimi 案例"Coder 缺 21 轮多轮循环是架构级缺陷"的论断部分不准确**——Coder 已能复现多轮，问题只在 nsd。
4. **443 与 :20080 外层 VM 字节码相同**（_$dJ[1] 114 元素一致），可复用本地 443 js 跑 :20080 沙箱。
